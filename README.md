# Safety Quiz Practice App

Open `index.html` in any browser (works offline). HTML + CSS + JS only.

```
SafetyQuizApp/
├── index.html        page layout
├── styles.css        look (light + dark mode)
├── app.js            quiz logic
└── data/questions.js question bank (window.SQ_DATA)
```

## Data
- Source: 職業安全健康局《職安健常識問答比賽手冊 2026》(Oct 2026) — `SQ_2026_Handbook.pdf`, 20 chapters, 1638 questions. Downloaded 2026-10-13 from https://www.oshc.org.hk/tchi/main/awards_campaigns/SQ2026/.
- The 2025 handbook is no longer used. Against 2025: 1530 questions are unchanged (only spacing or punctuation differs), 46 are reworded, 62 are new and 9 were dropped (lists below). Handbook numbers (ids) stay the same, so an old wrong-answer book still maps.
- The 2026 PDF has every character as real text, so no hand restoration was needed (the 2025 PDF had some characters drawn as shapes).
- Options that refer to each other (e.g. 「以上兩者皆是」) keep their A/B/C order even when shuffling.
- The `TND of … .xlsm` / `Copy of … .xlsm` files are an older edition and are not used.

## Defaults
50 questions · all chapters · Practice mode · 20 s per question · shuffle questions + A/B/C on. Change them on the setup page; "Reset to defaults" restores these.
Settings, results history and the wrong-answer book are saved in the browser (localStorage).
