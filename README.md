# Safety Quiz Practice App

Open `index.html` in any browser (works offline). HTML + CSS + JS only.

```
SafetyQuizApp/
├── index.html        page layout
├── styles.css        look (light + dark mode)
├── app.js            quiz logic
└── data/questions.js question bank (window.SQ_DATA)
```

## Data
- Source: 職業安全健康局《職安健常識問答比賽手冊 2025》(Jan 2025) — `SQ_2025_Handbook.pdf`, 20 chapters, 1585 questions.
- Up-to-date check (2026-10-08): the OSHC site lists only the 2025 handbook; the 2026 contest page (registration until 26 Oct 2026) gives no new handbook. Re-check https://www.oshc.org.hk/tchi/main/awards_campaigns/SQ2026/ before the contest.
- The `TND of … .xlsm` / `Copy of … .xlsm` files (1518 questions) are an **older edition**: 137 questions differ from the 2025 handbook (list below). The app uses the 2025 handbook.
- Some characters in the PDF are drawn as shapes, not text (e.g. 免 衛 腈 着 銹 蟎 氡 萘 鱲); these were identified and restored by hand.
- Options that refer to each other (e.g. 「以上兩者皆是」) keep their A/B/C order even when shuffling.

## Defaults
50 questions · all chapters · Practice mode · 20 s per question · shuffle questions + A/B/C on. Change them on the setup page; "Reset to defaults" restores these.
Settings, results history and the wrong-answer book are saved in the browser (localStorage).
